# OmniTech Services Specification

OmniTech provides six dedicated services across software development, IT helpdesk, systems operations, and data analytics.

---

### 1. Software & Application Development (`/services/software-development`)
- **Badge**: Full-Stack & Backend
- **Core Stack**: C#, ASP.NET Core, .NET, TypeScript, Next.js, React, SQL Server, Entity Framework Core, PostgreSQL.
- **Problems Solved**: Inflexible off-the-shelf software; manual data spreadsheets; disconnected workflows.
- **Deliverables**: Bespoke web applications, custom management systems, REST APIs, production-ready MVPs.

---

### 2. IT Support & Helpdesk (`/services/it-support`)
- **Badge**: Hardware, OS & Network
- **Core Stack**: Windows 10/11, Microsoft 365, Active Directory concepts, TCP/IP, DNS/DHCP, Printers, Service Desk ticketing.
- **Problems Solved**: Workstation crashes; Wi-Fi/DNS drops; Outlook & OneDrive sync freezes; unmanaged support tickets.
- **Deliverables**: Helpdesk ticket SLA tracking, hardware diagnostics, network topology guides, user provisioning.
- **Interactive Demo**: [OmniDesk IT Service Desk](/demos/it-service-desk)

---

### 3. Application Support & Systems Support (`/services/application-support`)
- **Badge**: L1/L2 Incident Management
- **Core Stack**: Incident Management, SQL query profiling, application log analysis, REST API debugging, system monitoring.
- **Problems Solved**: Silent background job failures; corrupt transaction data; API timeouts; un-reproduced production bugs.
- **Deliverables**: Incident root-cause analysis (RCA) reports, SQL correction scripts, uptime monitors, runbooks.
- **Interactive Demo**: [AppWatch Application Observability](/demos/appwatch)

---

### 4. Data Analytics & Business Intelligence (`/services/data-analytics`)
- **Badge**: KPIs, SQL & Reporting
- **Core Stack**: SQL (PostgreSQL, SQL Server), Advanced Excel, Power BI concepts, interactive data visualisations.
- **Problems Solved**: Data locked in disjointed spreadsheets; manual reporting overhead; lack of margin & revenue visibility.
- **Deliverables**: Interactive web BI dashboards, SQL views, executive KPI models, CSV dataset exports.
- **Interactive Demos**:
  - [InsightHub Sales BI](/demos/insighthub)
  - [ITOps Insights Performance Analytics](/demos/itops-insights)
  - [FinTrack Personal Cash Flow Analytics](/demos/fintrack)

---

### 5. Website Development & Management (`/services/website-development`)
- **Badge**: High Performance & SEO
- **Core Stack**: Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, Vercel, WCAG 2.2 AA.
- **Problems Solved**: Sluggish mobile websites; poor search engine visibility; broken viewports; neglected security updates.
- **Deliverables**: Modern corporate portals, high-conversion landing pages, structured maintenance retainers.

---

### 6. UI/UX Design & Technical Consulting (`/services/ui-ux-consulting`)
- **Badge**: Design Systems & Architecture
- **Core Stack**: Figma, Design Tokens, Tailwind CSS, Radix UI principles, WCAG 2.2 AA.
- **Problems Solved**: Cluttered confusing screens; inconsistent design elements; inaccessible layouts; architectural tech debt.
- **Deliverables**: Design systems, interactive wireframes, accessibility audits, technical roadmaps.
